## Fidelity process
- Capture actual current site references with URLs and dates using local browser if allowed; record references separately. Avoid relying on current website screenshots alone to copy proprietary design.
- Generate hero + first About section screenshot for desktop and mobile before proceeding. Keep same image placement, typography hierarchy, nav spacing and CTAs after approval.
- Screenshot review checkpoints: 1440×900, 1280×800, 768×1024 and 390×844; also full-page. Check hero subject remains visible and not covered by text.
- Compare against the **approved Dawn baseline**, not the Aureum screenshots. Document intentional deviations.

## States
Logo: unmodified, no clipping. Nav: default/hover/focus/active, mobile menu open/closed. CTA: default/hover/focus/disabled if inactive. Cards: gentle hover, click only when valid destination. Motion: reduced-motion version. 404: helpful links. Content never hidden until animation trigger.
